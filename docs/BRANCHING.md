# Branching consigliato

## Branch principali

- `main`: solo codice stabile e testato.
- `develop`: sviluppo integrato.

## Branch feature

- `feature/passcreator-client-branding`
- `feature/store-ready-version`
- `feature/woocommerce-renewal-engine`

## Regola pratica

Non lavorare direttamente su `main`. Ogni modifica dovrebbe passare da un branch e, idealmente, da pull request.
