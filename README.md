# Membership Manager – GitHub Repository

Repository ordinato per sviluppo e versionamento dei plugin Membership Manager.

## Struttura

```text
plugins/
  membership-manager-core/
  membership-manager-passcreator/
  membership-manager-woocommerce/
archive/original-zips/
docs/
tools/
```

## Plugin inclusi

- `membership-manager-core`: plugin base/core.
- `membership-manager-passcreator`: add-on Passcreator.
- `membership-manager-woocommerce`: add-on WooCommerce.

## Nota importante

Questa importazione non modifica la logica dei plugin. I file sono stati solo scompattati, ordinati e documentati per GitHub.

## Branch consigliati

- `main`: versione stabile.
- `develop`: integrazione delle prossime modifiche.
- `feature/passcreator-client-branding`: personalizzazione branding per associazioni/clienti.
- `feature/store-ready-version`: lavoro per distribuzione pubblica/store.

## Uso consigliato

Per installare in WordPress, zippare o caricare singolarmente le cartelle dentro `plugins/`.
